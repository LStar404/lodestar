# Lodestar 品牌书 · 命名系统

> 已落地（提交 `c666a18`）：`note-gen` → **Lodestar · 星引**。
> 核心思路：**名字不是词，是一套系统**——明面上是一个天文词，暗面里住着「洛 · 星 · 猫 · 404」。
> 这份文档保留推演过程与备选方案，便于日后回看「为什么是这些字」。

## 一、主推

| 层 | 内容 |
| --- | --- |
| 英文名 | **Lodestar**（/ˈloʊd.stɑːr/，LOHD-star） |
| 中文名 | **星引** |
| 一句话 | 以书为图，以记为星 |
| 英文副标 | Every note, a fixed star. |
| 首版版本号 | **4.0.4 · CDIV**（已发布） |

### 词义

*lodestar* 是真实存在的英文词：`lode`（航路、途径，古英语 *lād*「道路」）+ `star`，指**引路之星**，特指北极星；引申义是「圭臬、指路明灯」（*a lodestar for a generation*）。同源词 *lodestone* 是磁石——罗盘靠它指北。

一个「找方向」的词，正好是「教材 → 笔记 → 复习」这条路的隐喻；而 app 里的「全书导图」，本来就叫星图。

## 二、名字藏在哪里（解码表）

| 你的名字 | 藏在哪 | 怎么藏的 |
| --- | --- | --- |
| **洛** | Lodestar 的 `Lo` | 读音就是「洛」；拼写里只是两个不起眼的字母 |
| **星** | Lodestar 的 `star` | 明写，但读者只当它是一个天文词 |
| **L / Lstar** | `Lodestar` 的 L + 首字母 LSTAR | 大写时 `L★` 就是你的缩写 |
| **404** | 版本号 **4.0.4** | 不解释，懂的人自然懂 |
| **猫 / 喵** | **Felis** | 见下节——一座被星图删掉的猫座 |
| **喵（音）** | AI 助手唤醒词「喵」/ 中文「狸奴」 | 陆游：「裹盐迎得小狸奴，尽护山房万卷书」 |

### 猫为什么是 Felis（这是整个方案最漂亮的一层）

- 1799 年，法国天文学家 **Jérôme Lalande** 因为爱猫，在唧筒座与长蛇座之间造了一个星座 **Felis**（拉丁语「猫」）。1801 年 Bode 的《Uranographia》里画过它。
- 后来它被国际天文学联合会**废除**，从星图上抹掉了。
- 但它的最亮星 **HD 85951** 在 2018 年 6 月 1 日被 IAU 正式命名为 **Felis**。
- **星座被删了，那颗星还叫这个名字。**——这就是 404 最浪漫的解法：找不到的那只猫，其实还挂在天上。

于是「猫」和「404」在同一个典故里合流：**一个被删除的条目，仍然拥有一颗以它命名的星。**

## 三、品牌落地

- **Logo**：北极星四芒（收得很细的那种），中心留一枚极小的猫耳剪影——不放大看不见。
- **品牌符**：`⁂`（asterism，三星符）。它同时是天文词「星群」，又是排版里的「分节符」——直接拿来做笔记的分节线，一物两用。
- **空状态**：`这片星域还没有星`（替掉「知识，从这里开始积累」）。
- **404 页**：淡线描出已废除的猫座轮廓，文案「这只猫不在星图上」。
- **全书导图**：节点叫「星」，连线叫「星轨」；零散笔记自动聚成「星座」。
- **AI 编辑助手**：`Felīs`，中文「狸奴」；唤醒词「喵」。

## 四、备选（不同气质）

| 名字 | 出处 | 藏了什么 | 适合谁 |
| --- | --- | --- | --- |
| **洛诵** | 《庄子·大宗师》「副墨之子闻诸洛诵之孙」；成玄英疏：「**临本谓之副墨，背文谓之洛诵**」——照本抄叫副墨，合上书能背叫洛诵 | 洛 | 想要最中式、最文气的版本。一个词说尽「读书 → 抄录 → 内化」 |
| **Felis** | 同上，被废除的猫座 | 猫 + 404 | 想要极简四字母、极隐晦；不知道典故的人只看到一个拉丁词 |
| **Catasterism** | 希腊语 *katasterismos*「列入星座」，古书《Catasterismi》专讲人如何变成星星 | 一个词里同时住着 **cat** 和 **aster**（星） | 隐晦度天花板，但太长——建议留作「全书导图」功能的内部代号 |

> Catasterism 额外送一个隐喻：把散落的笔记**列入星座**。

## 四·补、合并方案：Lodestar × Catasterism

### 它们本来就共用一颗星

同出一源：PIE **\*h₂stḗr** → 英语 *star*、希腊语 *ἀστήρ*（aster）、拉丁语 *stella*、德语 *Stern*、梵语 *stṛ*。

- **Lodestar** = *lode*（路）+ ***star***
- **Catasterism** = *kata*（列入）+ ***aster***（星）

同一个词根，一件日耳曼外套、一件希腊外套。**所以「合并」在词源上早就完成了**，剩下的只是排版问题。

### 合并方式一（推荐）：焊符号，不焊词

让两个名字分工，用一个符号缝起来：

| 位置 | 名字 | 含义 |
| --- | --- | --- |
| 名 | **Lodestar** | 你跟着走的那颗星 |
| 礼 | **Catasterism** | 你走过去，成了星 |
| 动词 | **catasterize** | 把一条笔记列入星座 |
| 词标 | `Lodestar ⁂` | 见下 |

**为什么是 ⁂**：它的学名就是 *asterism*，而 catasterism = kata + **asterism**——两个名字在这个符号里接上了。而且 ⁂ 本来就是排版里的**分节符**，直接拿来做笔记分节线：天天出现，等于天天签名。

中文可以写成 **「星引 · 成星」**：引你到星，成你为星。

### 合并方式二：焊成一个词（会漏信息）

| 焊法 | 拆解 | 问题 |
| --- | --- | --- |
| **Asterlode** / 星径 | cat**aster**ism 的 aster + **lode**star 的 lode ＝ 星之路；洛在 lode 的读音里 | 已有一个同名小游戏（[cartridge.dev](https://cartridge.dev/game/asterlode)），检索会撞 |
| **Lodaster** | Lodestar 的字母一个不差重排（a d e l o r s t） | 会被当成错字自动纠正 → 只适合当内测代号 |
| **Cataster** | cat + aster，最短 | 贴着 catastrophe 的读音 |

**结论：词形上焊，信息会漏；符号上焊，两个名字都还在。**

## 四·补二、拉丁文与罗马文：只做铭，不做名

**名要能念，铭不必。** 拉丁文放在名字上要跟用户翻译一遍（Sidus / Dux Stellarum / Catasterismus 都有这个问题）；放在铭文上不用翻译——铭本来就是给人看不懂的。

| 层 | 内容 | 作用 |
| --- | --- | --- |
| 数字 | **404 → CDIV** | 版本号从工程痕迹变成碑铭：`4.0.4 · CDIV` |
| 字形 | 碑刻大写（全大写 + 宽字距） | 只用于封面、扉页、大标题；14px 会散，不进导航栏 |
| 词汇 | stella / sidus / via / feles / catasterismus | 笔记＝星、导图＝星座、路径＝via、助手＝猫、成图＝列入星空 |

格言 **AD ASTRA**（向星而行），只出现在关于页脚。

坑：CDIV 会被读成 CD+IV 或误认成光盘，所以它不上主标第一行。另外钟表匠把 4 写作 **IIII** 而不是 IV，将来若做 4.0.4 的纪念图标，可以只用一次。
