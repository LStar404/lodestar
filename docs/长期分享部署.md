# 长期分享阅读服务

本次实现只完成本地功能，没有部署、创建域名或上传笔记。

## 使用

在「分享 → 长期链接」选择章节或整本，保存分享版本。可预览、下载、更新同一固定路径，或撤销。分享是用户明确保存时的快照，日常编辑不会自动对外更新；更新需要点击「用当前内容更新」。已撤销的链接不可重新启用，需要创建新分享。已下载的文件不受撤销影响。

本地数据位于 `data/publications/<随机ID>.json`。同一 ID 的路径始终为 `/s/<随机ID>`；更新使用修订号防止覆盖另一窗口的改动。数据通过临时文件和原子替换保存，重启不改 ID。分享版本只包含选定笔记的渲染页面、必要的内嵌图片/字体和少量元数据，不包含原教材或模型密钥。

## 之后上线

必须使用独立的只读服务 `src.api.public_reader:create_app`，不能把本地编辑服务直接暴露到公网。阅读服务不提供管理 API、文件列表、API 文档或本地访问令牌，也不初始化原软件的 AppState、任务数据库或模型客户端。

示例 PowerShell（实际部署时使用固定 HTTPS 域名，并由反向代理转发至此服务）：

```powershell
$env:NOTE_GEN_PUBLICATIONS_DIR = 'D:\note-gen-publications'
python -m uvicorn src.api.public_reader:create_app --factory --host 127.0.0.1 --port 8788
```

`NOTE_GEN_PUBLICATIONS_DIR` 必须指向长期保存的分享目录。可让同机管理端与阅读端共享该目录，或通过受控同步把 `data/publications` 的完整 JSON 文件原子替换到阅读端。独立主机上必须同步更新和撤销记录，不能只复制一次就声称具备实时撤销；本次未实现跨主机自动同步。

部署后真实地址是 `https://你的固定域名/s/<随机ID>`。只有域名持续续费、服务持续运行、目录持久化并有备份，才能长期可用。本机界面目前仍明确标注「待部署」，不自动猜测域名或提供未经验证的公网地址。

当前访问模式是“持有随机链接即可读取”。随机 ID 使用 192 位熵；服务不返回列表。未来如需指定人员登录访问，应在阅读服务前加入身份验证，本次没有伪装成已经实现。页面响应禁止脚本、表单、外部资源及嵌入，禁止缓存与搜索引擎收录；撤销后同一路径返回 404。

备份应包含分享目录与笔记目录；恢复分享目录即可保留已有固定 ID。本次没有启动阅读服务或修改原有本地管理服务的网络边界。
